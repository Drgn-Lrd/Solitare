How To Use

Layout Editor
  • Click an empty grid point to place a tile on the current Layer tab. Click an existing tile to select it.
  • Drag a selected tile to move it, or use the D-pad to nudge it one snap-step at a time.
  • Every tile-width has 2 snap points across and 2 down — the same half-tile offsets Turtle/Pyramid/Irish Castle use.
  • The ★ marks the grid origin — build outward from it so left/right symmetry stays easy to eyeball.
  • Mirror auto-places a left/right mirrored tile whenever you place a new one (doesn't affect moving/removing).
  • Tiles can't be placed or dragged on top of another tile on the same layer — different layers overlapping is normal (that's how "covered from above" works), same-layer overlap isn't a valid board state.
  • Test Solvability checks whether the current tiles (any layer) can be fully cleared in some order, using the same free-tile rule Mahjong.html plays by.
  • Export is blocked unless the tile count is even — an odd count can never be fully paired off. It does NOT require exactly 144, but Mahjong.html's current tile-kind generator specifically expects 144 to actually play a layout, so anything else will export fine but won't load into a game yet.
  • Load opens a previously exported .json (or any of Turtle/Pyramid/Irish Castle's own files) back into the grid, re-centered on the origin star.
